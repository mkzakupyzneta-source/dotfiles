# WŁĄCZENIE (które z zainstalowanych rozszerzeń są aktywne) to INNA warstwa: klucze dconf
# `enabled-extensions` / `disabled-extensions`, wożone przez pulpit.ini (spec 8.3, plik
# dconf-wyjatki.txt). Ten plik NIE dubluje tamtej informacji — mówi tylko „ma być
# zainstalowane", nie „ma być włączone".
#
# Format jednej linii: <uuid>  <zrodlo>  [# komentarz]
#   zrodlo = ego      -> extensions.gnome.org. `lustro pulpit rozszerzenia` samo pobiera
#                        paczkę dla WERSJI GNOME SHELL WYKRYTEJ NA TEJ MASZYNIE
#                        (extension-info API, pole download_url) i instaluje
#                        (`gnome-extensions install --force`, bez sudo, per user).
#   zrodlo = lokalne  -> spoza extensions.gnome.org (pakiet apt, ręcznie rozpakowany zip).
#                        Apka TYLKO zgłasza brak — nie instaluje sama.
